# Проверка приложения

## Автоматические проверки

- [x] Нормализация HEX, включая короткие значения, пробелы и ошибки.
- [x] RGB/Oklab сверены с контрольными значениями; дистанция симметрична.
- [x] Точные совпадения выше приближённых; пара использует разные образцы.
- [x] Перестановка двух входных цветов сохраняет ранжирование.
- [x] Проверены общий оптимум пары и разрешение равных оценок.
- [x] Фильтры комбинируются; случайный выбор обрабатывает пустую и единственную палитру.
- [x] В каталоге 348 + 233 палитры, без пропусков нумерации и битых ссылок цветов.
- [x] Проверены контрольные палитры обоих томов и цвета 8–9 палитры II №152.

Команда: `npm test`. Отдельная проверка сборки: `npm run build`.

## Ручные сценарии

| Сценарий | Действия | Ожидаемый результат |
| --- | --- | --- |
| Случайная палитра | Несколько раз нажать «Новое сочетание» | Меняются номер, цвета и пояснение; нет немедленного повтора |
| Один цвет | Ввести `#F80` и выполнить поиск | Значение нормализуется в `#FF8800`, появляются исходные палитры |
| Два цвета | Добавить второй, ввести `#064F6E` и `#004F46`, выбрать Том II и 9 цветов | Среди результатов II №152 с точным совпадением пары; все 9 цветов сохранены |
| Неверный HEX | Ввести `zzzz`, нажать поиск | Ошибка под полем, фокус возвращён в поле, приложение продолжает работать |
| Удалить второй цвет | Убрать второй оттенок и повторить поиск | Поиск снова использует один цвет |
| Пустая выборка | Выбрать Том I и 9 цветов | Понятное пустое состояние; сброс фильтров возвращает палитры |
| Избранное | Сохранить, перезагрузить, открыть «Избранное» | Палитра сохранена; удаление работает и не теряет клавиатурный фокус |
| Избранное с фильтром | Выбрать фильтр, скрывающий сохранённые палитры | Есть объяснение и кнопка сброса фильтров |
| Копирование | Нажать на образец, затем «Копировать палитру» | Буфер содержит правильный HEX, затем все HEX через запятую |
| Клавиатура | Перемещаться Tab, менять вкладки стрелками, открыть и закрыть «О коллекции» | Фокус видим, Enter работает, Escape закрывает диалог |
| Телефон | Проверить ширину 390 и 320 px, открыть 9 цветов | Нет горизонтального скролла страницы; образцы сгруппированы по 3, HEX читаются |
| Путь репозитория | Запустить сборку с `--base=color-dictionary` | HTML, CSS, JS, JSON и favicon доступны под префиксом |
| Источники | Открыть «О коллекции» | Видны источники обоих томов и оговорка о независимой сверке второго |

Состояние публикации в GitHub Pages проверяется после загрузки проекта в репозиторий пользователя.

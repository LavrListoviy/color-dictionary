# Источники каталога

Импорт выполнен 22 октября 2026 года. В `data/catalog.json` находятся **581 сочетание: 348 из первого тома и 233 записи второго тома**, а также 173 записи оттенков. Приложение работает с локальной копией данных и не обращается к этим сайтам при подборе.

## Что считается источником

Автор оригинальных сочетаний — **Сандзо Вада (Sanzo Wada, 1883–1967)**. Современные книги изданы Seigensha. Это неофициальное приложение; издательство его не выпускало и не проверяло.

| Часть | Источник цифровых фактов | Что перенесено |
| --- | --- | --- |
| Том I, №1–348 | [mattdesl/dictionary-of-colour-combinations](https://github.com/mattdesl/dictionary-of-colour-combinations) | Английские названия, CMYK, производные RGB/HEX, принадлежность оттенков сочетаниям |
| Том II, №1–233 | [Общедоступный каталог Wada.ink](https://wada.ink/palettes), автор Allison Peña | Названия, числовые значения цветов и состав сочетаний из публичных карточек и JSON-индексов страницы |

Для первого тома исходную оцифровку выполнил **Dain M. Blodorn Kim** ([dblodorn/sanzo-wada](https://github.com/dblodorn/sanzo-wada)); **Matt DesLauriers** исправил часть данных и выполнил преобразование CMYK в sRGB через ICC-профили. Использованный набор распространяется под **MIT**. Обязательное уведомление сохранено в [THIRD_PARTY_NOTICES.txt](../THIRD_PARTY_NOTICES.txt).

Второй том перенесён из сторонней оцифровки. [Страница автора Wada.ink об источнике](https://wada.ink/about) указывает 348 и 233 сочетания и отделяет собственные описания сайта от исторических цветовых данных. [Главная страница](https://wada.ink/) разрешает копировать и использовать числовые значения цветов; [условия сайта](https://wada.ink/terms) не являются открытой лицензией на весь сайт. В этот проект **не перенесены** его тексты, комментарии, интерфейс, CSS, иллюстрации, фотографии или пользовательские палитры. Лицензия MIT первого набора не приписывается второму источнику.

Полный проверенный PDF второго тома при подготовке каталога не получен. Бумажная книга независимо не сверялась: полнота и нумерация второго тома воспроизводят именно 233 записи Wada.ink. Это ограничение нельзя трактовать как подтверждение издательства.

## Печатные издания и расхождение количества

- [Том I у Seigensha](https://en.seigensha.com/books/978-4-86152-247-5/): ISBN 978-4-86152-247-5, 348 сочетаний.
- [Том II у Seigensha, английская страница](https://en.seigensha.com/books/978-4-86152-772-2/): ISBN 978-4-86152-772-2, 72 сезонных сочетания и 165 примеров дизайна.
- [Том II, японская страница издательства](https://www.seigensha.com/books/978-4-86152-772-2/) противоречит сама себе: в основном описании указаны **161** пример, а в списке особенностей — **165**. [Японский каталог издательства 2024 года](https://www.seigensha.com/wp-content/uploads/seigensha_catalog2024.pdf) также указывает 72 + 161.

Поэтому импорт использует фактическую непрерывную нумерацию открытого каталога **1–233**, не дополняя его выдуманными записями до 237. Первые 72 палитры второго тома содержат 3–7 оттенков. Среди остальных примеров встречаются сочетания из 8–9 оттенков.

## Точность экранных цветов

HEX — цифровое приближение печатных образцов. Цветопередача зависит от преобразования CMYK, профиля монитора и условий просмотра. Из этого приложения нельзя выводить точное соответствие краске или печатному оттиску.

Имена сохранены по источникам. Одинаковое нормализованное имя с одинаковым HEX объединяется; варианты одного имени с разными HEX сохраняются отдельно. Одинаковый HEX при разных названиях сам по себе не считается основанием для объединения. Приложение рассчитывает близость по экранным sRGB-значениям, а не использует готовые LAB разных источников с потенциально разными белыми точками.

В исходном наборе первого тома у **Dull Violet Black** указан невозможный CMYK `[95, 106, 38, 50]`. Его готовый HEX `#1e0e3f` сохранён, поле CMYK для этой записи пропущено. Значение не исправлялось догадкой.

Русские описания в приложении создаются его алгоритмом по составу палитры, светлоте и цветовому контрасту. Это собственная интерпретация приложения, не цитата и не перевод авторского текста Вады или издательства. Подбор по пользовательским оттенкам возвращает ближайшие исходные сочетания, не перекрашивая их.

## Обновление и контроль импорта

Требуется Node.js 22 или новее, без дополнительных библиотек:

```powershell
node scripts/import-catalog.mjs
```

Для повторного импорта из отдельно сохранённых снимков источников:

```powershell
node scripts/import-catalog.mjs --v1-json="C:\path\colors.json" --wada-html="C:\path\wada-palettes.html"
```

Скрипт записывает `data/catalog.json` и `data/source-manifest.json`. Манифест содержит URL, SHA-256 загруженных исходников, время импорта и количество записей. Полный HTML стороннего сайта в проект не включён.

Импорт проверяет 159 исходных цветов первого тома, непрерывную нумерацию 348 и 233 сочетаний, существование каждого цвета, допустимый HEX и согласованность каждой карточки второго тома с отдельным JSON-индексом той же страницы. Это проверка целостности оцифровки, а не независимая сверка с книгой. При изменении структуры или количества данных импорт останавливается и требует проверки источника.
